# iOS platform folder

This tree was authored without the Flutter SDK on PATH, so the Xcode
project is not generated here.

From the parent `mobile/` directory:

    flutter create --org com.azieeliab --project-name foldlock .

Then open `ios/Runner.xcworkspace` in Xcode.
Offline. No analytics. Not a store IPA. Zip-class SOTA compression engine.
